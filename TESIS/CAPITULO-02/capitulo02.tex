
\section{Ingeniería de Requisitos }
La Ingeniería de requisitos es el desarrollo de software que abarca todas las actividades para descubrir, analizar y mantener las necesidades 
de los usuarios.El propósito principal es traducir las ideas y problemas de negocio en especificaciones técnicas claras y verificables 
para evitar errores costosos.


\subsection{Proceso de elicitación de requisitos}
La elicitación de requisitos se la define como una etapa critica dentro de la ingeniería de requisitos, cuyo objetivo principal es comprender, estructurar 
y documentar las necesidades de los usuarios que se busca satisfacer con un producto de software. 

Según el modelo MoDeMaRE (Model to Develop and Manage Requirements Engineering), la elicitación es la segunda etapa del proceso,precedida por 
una Etapa Temprana donde se reconoce el contexto y se comprende el dominio del problema \cite{serna2016documentar}
