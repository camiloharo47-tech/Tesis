

\subsection{Objetivo general}
Desarrollar un sistema multi-agente basado en Model Context Protocol, para la generación automatizada de documentos de especificación de requisitos de software conforme al estándar IEEE 830-1998, a partir de audios de entrevistas a Product Owners.

\subsection{Objetivos específicos}

\begin{itemize}
    \item Establecer el marco teórico y conceptual que fundamente la investigación, abordando los fundamentos de ingeniería de requisitos, metodologías de elicitación, el estándar IEEE 830-1998, modelos de lenguaje de gran escala, arquitecturas multi-agente y el MCP.
    
    \item Desarrollar el sistema multi-agente basado en MCP e inteligencia artificial generativa, mediante la metodología de desarrollo Scrum, integrando agentes especializados para la transcripción de audio de entrevistas, extracción y clasificación de requisitos funcionales, enriquecimiento contextual mediante búsqueda web, y generación estructurada del documento SRS conforme al estándar IEEE 830-1998.
    
    \item Evaluar los documentos SRS generados por el sistema mediante métricas basadas en LLMs y juicio de expertos en ingeniería de requisitos, aplicando como criterios de validación, comparando los resultados obtenidos frente a la elaboración manual del documento.
\end{itemize}
